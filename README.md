<h1>Get the pull shark badge (and many more)</h1>
What to do for Pull Shark:
1. Fork this repo
2. Make a pull request
3. Wait for me to merge it
4. Done!
For Quickdraw:
1. Open an issue
2. Close it right after opening it
3. Done!
For YOLO:
1. Fork this repo
2. Invite me as collaborator
3. Once I accept the request, create a pull request and add me as reviewer
4. Merge the request
5. Done!
